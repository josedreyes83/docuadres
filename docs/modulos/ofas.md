# 🏛️ OFAS — Gestión Ciudadano

**9 HUs** · Epic #4012 · Riesgo: Medio (0% Done, 9 Committed)

## ¿Qué hace?

Portal web independiente que permite a ciudadanos radicar solicitudes de **Operaciones de Fortalecimiento de la Aseguradora** ante ADRES. No interactúa con el flujo principal de GiroDirecto — solo comparte la infraestructura de autenticación.

## Flujo del portal

```
Auth → Portada → Formulario → Validar Solicitante
    → Info Garantías → Términos → Borrador → Radicar
```

## Las 6 OFAS

| # | OFAS | Descripción |
|---|------|-------------|
| 1 | Garantías | Solicitud de garantías financieras |
| 2 | Línea de Crédito Directo | Líneas de crédito directas a EPS |
| 3 | Compra de Cartera | Adquisición de cartera de EPS |
| 4 | Convenios Financieros | Acuerdos financieros institucionales |
| 5 | Capital Garantía | Aporte de capital como garantía |
| 6 | Adquisición de Títulos EPS | Compra de títulos de deuda EPS |
