# Glosario — GiroDirecto ADRES

| Término | Definición |
|---------|------------|
| **ADRES** | Administradora de los Recursos del Sistema General de Seguridad Social en Salud |
| **EPS** | Entidad Promotora de Salud — aseguradora de los afiliados al SGSSS |
| **IPS / Prestador** | Institución Prestadora de Salud — hospital, clínica o laboratorio |
| **REPS** | Registro Especial de Prestadores de Salud — base oficial de IPS habilitadas |
| **ERPF** | Estructura de Recaudo y Pago de Facturas |
| **MIPRES** | Mi Prescripción — sistema para tecnologías no cubiertas por el Plan de Beneficios |
| **Condición de Giro** | Criterio que define cuándo aplica GD para una EPS (ej: deuda > X%) |
| **Giro Límite** | Monto máximo a girar a un prestador en un período determinado |
| **Ventana de Giro** | Período temporal en que se agrupan y procesan los giros |
| **Pre-Liquidación** | Cálculo previo de montos antes de la liquidación definitiva |
| **Postulación** | Proceso por el cual un prestador aplica para recibir el giro directo |
| **Liquidación** | Cálculo definitivo y aprobación del monto real a girar |
| **Validación** | Verificación de facturas y servicios para determinar elegibilidad |
| **Alistamiento** | Configuración de datos maestros del sistema |
| **Hangfire** | Motor de background jobs para reportes asincrónicos |
| **OFAS** | Operación de Fortalecimiento de la Aseguradora — portal ciudadano de garantías |
| **SIIFA** | Sistema Integral de Información Financiera y Asistencial (MinSalud) |
| **BDUA** | Base de Datos Única de Afiliados |
| **CCF** | Caja de Compensación Familiar |
| **ERP** | Enterprise Resource Planning — sistema de gestión financiera y contable |
| **ORFEO** | Sistema de gestión documental institucional |
| **SMTP** | Protocolo de envío de correos electrónicos (notificaciones TOBE) |
| **Azure Auth** | Servicio de autenticación en la nube Microsoft (objetivo TOBE) |
| **SGSSS** | Sistema General de Seguridad Social en Salud |
